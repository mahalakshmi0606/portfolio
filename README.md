# Portfolio Website

This repository contains the source code for my personal **Portfolio Website** — a responsive web application built to showcase projects, skills, experience, and contact information.

This portfolio is designed to highlight my work and help potential employers or collaborators learn more about me in a clean and modern way.

---

## 🌟 Features

- Fully Responsive Layout
- About Me Section
- Skills Showcase
- Projects Gallery with Links
- Contact Form
- Smooth Navigation
- Modern UI/UX Design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap (optional)
- FontAwesome Icons

## 🛠️ Setup Instructions

### 1. Clone the Repository

```
git clone https://github.com/mahalakshmi0606/portfolio.git
```

### 2. Navigate into the Folder

```
cd portfolio
```

### 3. Open in Browser

Just open the `index.html` file in your browser:

```
double-click index.html
```

or

```
open index.html
```
